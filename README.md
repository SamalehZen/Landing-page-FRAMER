# CureNast · Next.js Landing Page

Pixel-perfect, high-performance recreation of the CureNast Framer landing page in Next.js 14 (App Router) with Tailwind CSS 4, Framer Motion micro-interactions, and rich accessibility/SEO enhancements.

## Tech Stack

- **Framework:** Next.js 14 (App Router, TypeScript)
- **Styling:** Tailwind CSS 4 + custom design tokens
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Fonts:** Poppins, Inter, Instrument Sans via next/font

## Highlights

- Full section parity with CureNast (hero, services, about, why choose us, doctors, testimonials, online consult, blog, FAQ, CTA, footer)
- Social proof badges, responsive doctor grids, animated accordions, and testimonial carousel with numbered navigation
- Gradient-rich hero, glassmorphism cards, orbiting CTA badges, and sticky header with dynamic glass effect
- Accessibility upgrades (skip link, aria labels, keyboard-friendly accordions) and schema.org JSON-LD for SEO
- Optimized local imagery powered by `next/image` and reusable data-driven components

## Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to explore the landing experience.
